# IUT Student Information System (IUT SIS)

An interactive, responsive single-page web portal designed for undergraduate students at the **Islamic University of Technology (IUT)**.

---

## 🌟 Key Features

- **Cinematic Authentication Portal**: Clean login experience with IUT architectural artwork, Dhaka live time pill, and credential validation.
- **Academic Dashboard**: High-level overview displaying standing, current term GPA, credit progress, and quick academic actions.
- **Student Profile**: Comprehensive scholar profile with academic milestones, department details, and advisor contact.
- **Semester Results & Transcripts**: Interactive semester tab switcher (Semesters 1 through 4) with GPA breakdown, course grades, credits earned, and status chips.
- **Examination Schedules & Admit Card**: Timetable for mid-term and semester final exams, downloadable/printable official exam admit card modal with dynamic roll and verification stamp.
- **Faculty Course Feedback**: Anonymous course evaluations with star ratings across teaching quality, material clarity, punctuality, and overall delivery.
- **Weekly Class Timetable**: Daily schedule slot breakdown with lecture room locations, instructor credits, and prayer breaks.
- **Circulars & Notices**: Departmental notifications, examination protocols, and financial advisories with categorized filter tabs and unread counters.
- **Academic Calendar**: Interactive term timelines, holiday dates, exam schedules, and industrial training intervals.
- **Official Fees & Payments (AB Bank)**:
  - Full matriculation breakdown for B.Sc. Engineering & BBA programmes.
  - Reactive switcher between **Non-Residential ($3,000/yr)** and **Residential ($4,500/yr)** schedules.
  - Interactive pending balance tracking and installment schedule.
  - Official payment history and printable **AB Bank 3-Part Deposit Challan** slips.
- **Theme Support**: Dark and Light theme toggle with persistence.

---

## 🚀 Getting Started

### Run Locally
Open `index.html` directly in any modern web browser, or serve it using VS Code Live Server / Python HTTP server:

```bash
# Using Python
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
